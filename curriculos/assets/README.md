# Foto de perfil

Coloque a foto real neste diretorio com um destes nomes:

- `profile-photo.jpg`
- `profile-photo.jpeg`
- `profile-photo.png`
- `profile-photo.webp`

O gerador `curriculos/generate.py` embute a imagem automaticamente nos HTMLs e PDFs.

Se nenhum desses arquivos existir, o curriculo usa um avatar com as iniciais `LC`.
